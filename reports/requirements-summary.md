# 需求摘要

## 專案基本資料
- 課程：TAICA「生成式 AI：文字與圖像生成的原理與實務」
- 專案主題：人工智慧與資訊安全：AI 時代的風險、挑戰與防護
- 作者：資管三A 1311531039 葉家榕
- 使用工具：Gemini CLI（實際 CLI／模型版本待執行時記錄）
- 成品：LLM Wiki、GEMINI.md、25 張互動式 HTML 教學簡報、Workflow、檢查報告及 GitHub Pages 網站。

## 目標對象
大學生及一般資訊管理系學生，假設具備基本電腦使用經驗，但不要求具備資安專業背景。

## 功能需求
1. Wiki 至少納入 5 篇公開資料；本專案來源索引目前列出 6 筆。
2. 先討論、後生成：先由 Gemini CLI 討論研究範圍、分類與資料需求，確認後再進行 Ingest／生成。
3. 建立 GEMINI.md，規範語言、來源、Wiki 格式、安全邊界與品質檢查。
4. HTML 簡報固定 25 張，採深色 Cyber 視覺風格。
5. 簡報提供動畫轉場、目錄、鍵盤左右切換、進度條、互動案例、測驗與參考資料。
6. 專案可由 GitHub Pages 公開瀏覽。

## 非功能需求
- 使用繁體中文。
- HTML、CSS、JavaScript 分離。
- 不依賴外部套件才能執行核心功能。
- 來源可追溯，避免無根據的數字與主張。
- 手機與桌面皆可閱讀。
- 資安內容以防禦、治理、隱私及安全使用為主。
