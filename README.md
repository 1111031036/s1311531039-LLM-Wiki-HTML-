## 專案內容
- `GEMINI.md`：Gemini CLI 專案規則。
- `wiki/`：六大領域的知識頁面與首頁。
- `sources/`：研究來源清單、來源摘要與查核紀錄。
- `presentation/`：25 張投影片的互動式 HTML 簡報。
- `workflow/`：Loop / Graph 流程、節點說明及品質閘門。
- `reports/`：需求摘要、執行檢查報告模板與心得初稿。
- `screenshots/`：請放入 Gemini CLI 真實討論與執行截圖。

## 如何預覽簡報
請先將 ZIP 完整解壓縮，再以瀏覽器開啟根目錄的 `index.html`。首頁的 Wiki、來源、Workflow 與報告連結均已提供 HTML 閱讀頁面；簡報可由首頁直接開啟。無需安裝套件或啟動伺服器。

## GitHub Pages 部署
1. 建立 GitHub Repository，建議名稱 `AI-Information-Security-Wiki`。
2. 將本專案根目錄所有檔案上傳至 Repository 根目錄。
3. Repository 設為 Public。
4. 進入 Settings → Pages。
5. 在 Build and deployment 選擇 `Deploy from a branch`。
6. Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
7. 等待部署完成，網址通常為 `https://<GitHub帳號>.github.io/AI-Information-Security-Wiki/`。
8. 如果想讓簡報直接成為首頁，可將 `presentation/index.html` 複製到根目錄並命名為 `index.html`；目前根目錄已提供導覽首頁。
